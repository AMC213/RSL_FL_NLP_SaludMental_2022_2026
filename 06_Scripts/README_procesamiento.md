# Procesamiento de Datos y Generación de Gráficos

- **Herramientas utilizadas:** Microsoft Excel / Hojas de cálculo y gestor bibliográfico.
- **Procedimiento:** 
  1. Los conteos bibliométricos (evolución temporal 2022–2026 y distribución editorial) se calcularon mediante tablas dinámicas sobre los 86 registros exportados de Scopus.
  2. Los gráficos comparativos (Fig. 2, Fig. 3 y Fig. 4) se generaron directamente a partir de las matrices de síntesis cuantitativa consolidada en hoja de cálculo.
  3. El diagrama de flujo (Fig. 1) se elaboró siguiendo la plantilla estándar PRISMA.
- **Nota:** No se emplearon scripts externos en Python o R para el procesamiento estadístico de esta revisión.
